# Batch_01 阶段 1 分析计划

## 目标
从现有 QIIME2 产物形成可追踪、可核验的 ASV count、taxonomy、样本元数据与 R phyloseq 对象。此阶段**不做**正式的生物学差异结论。

## 顺序
1. 沿用 `results/qc/stage1_report.md` 已通过的QIIME2导出、ASV/taxonomy/代表序列一致性、计数及测序深度核查；输入无变化时不重复运行。
2. 复用现有原始ASV计数及分类文件，不重跑DADA2、SILVA或重复导出。
3. 以已确认设计文档的完整名单建立33行metadata映射方案，仅读取ASV表头核对样本名，不扫描计数或重做ASV质量检查。
4. 检查分析模块、运行阶段、轮次、混合来源、采样时间、分级母样和缺失环境信息；原始metadata保持不变，方案通过现有脚本在内存复现并集中写入原综合报告。
5. 当前按用户要求暂不构建最终phyloseq对象，待后续核查与交付范围确认；未来构建时再验证样本数、特征数、方向、ID及对象内容一致性。
6. 输出 QC 报告和可复现脚本；将异常列表交由用户确认，再开展后续分析。

## 阶段验收
- 33 个样本与五组设计均有来源可核验的记录。
- ASV 表为未经稀释/未经相对丰度化的原始非负整数计数。
- 样本 ID 无重复、无无意丢失或静默改名。
- ASV 表与 taxonomy 的特征 ID 对齐；metadata 与 count table 样本 ID 完全一致。
- phyloseq 构建成功，`nsamples`、`ntaxa` 与输入表核对一致。
- 脚本、日志和来源记录完整；不覆盖已存在的结果。

## 暂不开展
alpha/beta 多样性显著性检验、差异菌群检验、共现网络、组装过程和机器学习。待阶段 1 通过并确认研究设计后逐项选择。

## 2026-11-02 五模块目标与统计限制（当前有效）

来源为 `experiment_design.md` 的当日已确认设计修正及用户完整五模块清单。33行数据是取样记录数；4个反应器标签跨轮次使用，不能把全部样本当独立重复，也不能将五模块统一视为五组可直接检验的处理条件。

| 模块 | 记录数与分析目标 | 统计限制及当前处理 |
|---|---|---|
| G1 | 8行；描述四个原反应器低C/N启动前后变化 | 同一反应器前后配对；G1内部有两个operation_phase，不能混作同质阶段。絮状/颗粒设计类型各对应两个反应器标签，独立性与来源还需方法级核验；不直接作8个独立重复 |
| G2 | 2行B2/D2；描述DO设定5 mg/L阶段末状态 | 仅两行、来自新R2/新R4；不补造其他反应器该阶段数据。记录数不等于充分独立生物重复数 |
| G3 | 4行A2/B3/C2/D3；描述DO设定3 mg/L阶段末及连续阶段变化 | 与G2同一轮连续运行；B2→B3、D2→D3为两对反应器内记录。G2/G3的DO、时间和阶段共同变化，不能据此分离DO因果效应；不将2+4行作独立两组t检验/Wilcoxon或无约束置换 |
| G4 | 15行；区分四份恢复后初始基线与11份低DO后期样本，按反应器描述时间序列 | 用户确认初始样本在切换低DO前取样，恢复阶段设置3 mg/L；后期30/76/145d均在25–145d、设置0.5±0.2 mg/L，可称设计稳定运行期。各日4/3/4/4行不平衡且相关，实际稳态证据另核验，不把15行全归同一稳定条件 |
| G5 | 4个级分；描述同一R1母样不同粒径组分的群落组成 | 只有一次母样采样事件，每个粒径一个组分；不存在可由这4行估计的独立生物重复变异，不做粒径组间显著性检验，也不代表跨反应器普遍效应 |

### 共同约束与方法门控

- G1结束后原R1/R2混合均分到新R1/R2，原R3/R4混合均分到新R3/R4：两个已记录混合来源块不自动等于两份已验证独立生物重复。接收同一混合污泥的反应器不能当独立初始生物重复；其相关性会通过前源延续到保存恢复后的新实验，不能在分析G4时忽略。
- 反应器、污泥设计类型、来源块、运行时间和阶段可能混杂。重复测量模型、配对方法或受限置换仅是未来可评估的方法，不因能指定随机效应或分层就自动满足识别性、有效样本量和可交换性；本次不运行这些方法。
- 第22天仅为5→3 mg/L过渡及稳定过程，无本批稳定节点样本；不归入G2/G3稳定取样，不用该日构造额外观察。
- G5和G4-R1来自同一运行实体，G5为第145天后延长18天的同一母样分级。不能将模块G4与G5视为独立处理比较；第163天是原表推算，日历日期仍未知。
- DO设定值与实测值分列；未知DO及其他环境参数为NA。无逐样本可靠实测数据时不开展依赖这些参数的相关、回归、环境排序或因果解释；不插补采样条件。
- 不为使模型可运行而任意合并阶段、删除不平衡样本或调过滤阈值。不将ASV相对丰度解释为严格绝对丰度，不把分类注释当成功能基因或活性证据。
- 开始任何推断前，必须针对具体问题核验实验单位、配对/重复结构、混合谱系、来源与组别混杂、独立单位数、模型可识别性、置换限制及方法前提；无法验证时只交付描述性结果。

### 当前交付与复现

`scripts/stage1_pipeline.R --review-design` 仅生成设计/metadata映射报告：读取现有metadata、已确认设计和ASV表头，在内存构造附加字段方案，以断言核对33样本一一映射、五模块数量、连续轮次、两次混合、DO设置/未知实测以及同一母样关系，追加到唯一 `results/qc/stage1_report.md`。原始metadata与现有计数/Artifact不改写，无新中间文件。原有 `--review-metadata` 在发现当前已确认设计时转到此入口，避免重复输出过时的“五组尚未确认”结论。对象构建与统计推断继续暂缓。
