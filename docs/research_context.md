# 研究背景与边界

## 研究主题
AOA-AGS（实验使用的具体系统名称以研究原始记录为准）系统的 16S rRNA 扩增子微生物群落研究。

## 整体研究目标
- 识别不同反应器及运行阶段之间具有一定可重复性的微生物生态特征。
- 在具备可靠分组/运行参数时，评估群落结构与条件之间的关联。
- 谨慎探索群落组装机制、功能类群及可稳定验证的机器学习特征。

## 现有研究条件
- 多批次数据，部分反应器具有多个采样时间/运行阶段。
- 数据来自同一家测序服务商；历史信息指示采用 338F/806R 引物。需按实际批次文件复核测序和处理流程。
- 计算环境：Windows VS Code + WSL Ubuntu + Conda；QIIME2/DADA2，后续 R/phyloseq。
- 某些运行条件和采样时刻环境参数不完整；不得用初始设定值冒充采样实测值。
- 不进行新的独立验证实验；模型研究尤其要避免数据泄漏并按反应器分组验证。

## 方法学边界
- 16S 功能类群注释仅是参考数据库和文献支持的分类推断，需记录依据和置信度。
- 功能预测并非直接测得功能或反应速率。
- 群落组装、机器学习及环境驱动分析必须匹配样本量、时间序列结构和有效元数据，不能自动全做。
